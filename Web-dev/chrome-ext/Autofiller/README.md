# Autofiller

Autofiller is a Chrome extension that fills simple, non-sensitive form fields for you.

Save basic details like your name, email, phone number, and address. Then open a form, choose the fields you want to fill, and click **Fill**.

## Features

- Save a basic personal profile locally
- Fill selected form fields with one click
- Supports up to five fields per page
- Works with common form inputs such as text fields and textareas

## Privacy

- All data is stored locally in your browser
- No cloud sync
- No analytics
- Does not save passwords or payment details
- Does not submit forms automatically

## Installation

1. Download or clone this repository.
2. Open Chrome and go to `chrome://extensions`.
3. Turn on **Developer mode**.
4. Click **Load unpacked**.
5. Select the Autofiller folder.
